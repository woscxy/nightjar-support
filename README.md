# Nightjar support site

The support page and privacy policy for Nightjar: Dark Mode for Safari, a Safari extension for iPhone, iPad and Mac that darkens websites without a dark theme of their own.

- Support: https://woscxy.github.io/nightjar-support/
- Privacy policy: https://woscxy.github.io/nightjar-support/privacy.html

## Feedback

Please email cxy130434@gmail.com rather than opening an issue; issues are switched off here. In the extension, **Report a Problem** fills in the details we need.

This repository is published from the app's source, so changes made here directly are replaced on the next update.
